# Earn & Arm — 23 January 2027

หน้าร่วมแสดงความยินดีอยู่ที่ `wishes.html` เชื่อม Google Apps Script ไปยังชีตของผู้ใช้ พร้อมข้อความอวยพร รูปถ่าย สลิปส่วนตัว และดาวน์โหลดโปสการ์ด
ใช้ QR ธนาคารกรุงไทยต้นฉบับจากผู้ใช้ โดยไม่แก้ไขภาพ และตรวจรหัสแล้วว่าตรงกับพร้อมเพย์ 0623452359 ชื่อผู้รับนางสาวชุติกาญจน์ พยัคฆะ
รายละเอียดการเชื่อมต่อและทดสอบอยู่ใน `google-apps-script/README.md`

หน้าเว็บ HTML/CSS/JavaScript แบบ static อยู่ใน `dist/` ไม่ต้องติดตั้ง dependencies

## ใช้งาน

- เปิดเว็บแล้วเลือก **ปรับแต่งการ์ด** เพื่อเปลี่ยนชื่อ วันงาน สถานที่ ข้อความและกำหนดการ
- เพิ่มรูป เพลง MP3/M4A/WAV/OGG และวิดีโอ MP4/WebM หรือ YouTube
- แกลเลอรีเพิ่มได้สูงสุด 20 รูป จัดลำดับ แก้คำบรรยาย เลื่อนแนวนอน เปิดเต็มจอ ใช้ปุ่มลูกศร/ปัดภาพ และเล่นสไลด์โชว์ได้ เริ่มต้นว่างเพื่อรอรูปจริง
- เพลงเริ่มต้นใช้ไฟล์ `atlasaudio-wedding-606284.mp3` ที่ผู้ใช้แนบ เล่นเต็มเพลงและวนซ้ำเมื่อแตะเปิดคำเชิญหรือปุ่มเพลง โดยย้ายเฉพาะค่าเพลงในร่างเก่าและเก็บรูปแกลเลอรีเดิมไว้
- เพลง YouTube ที่เคยเลือกคือ “ดาวหางฮัลเลย์ — fellow fellow” (`WtcKJtwMD2E`) ตั้งช่วงตัวอย่าง 01:00–01:30 และปรับเวลาได้
- ทดสอบ YouTube ทั้ง youtube.com และ youtube-nocookie.com แล้วได้ error 150 (ไม่อนุญาตการฝัง) จึงแสดงลิงก์เปิดฟังบน YouTube ตามเวลาเริ่ม แทนการอ้างว่าเล่นเสียงบนการ์ดได้
- เวลาเริ่ม/จบและวนซ้ำรองรับผ่าน IFrame API สำหรับคลิปที่ฝังได้ ส่วนไฟล์เสียงอัปโหลดรองรับเลือกช่วงเวลาและวนซ้ำเช่นกัน
- ไม่ได้ดาวน์โหลด แยกเสียง ตัดเพลง หรือแปลงเพลงของ YouTube เป็นดนตรีล้วน หากต้องการเวอร์ชันบรรเลงให้เลือกไฟล์เสียงที่มี
- ร่างบันทึกใน IndexedDB ของเบราว์เซอร์ปัจจุบัน การแก้ไขร่างไม่เปลี่ยนเนื้อหาเว็บของผู้เข้าชมรายอื่น
- **ดาวน์โหลดการ์ด HTML** จะรวมไฟล์รูป เพลงและวิดีโอที่อัปโหลดเป็นไฟล์ HTML เดียว พร้อมปิดเครื่องมือแก้ไข
- ใช้ข้อมูลจากรูปการ์ดที่เจ้าของส่งให้: ครูเอิญและครูอาร์ม วันเสาร์ที่ 23 มกราคม 2570 เริ่ม 07.00 น.
- ปุ่ม “ดูการ์ดเชิญฉบับเต็ม” เปิดรูปต้นฉบับโดยคงไฟล์เดิมไว้
- ใช้ลิงก์ Google Maps ที่ถอดจาก QR ของการ์ดต้นฉบับ
- ชื่อเจ้าสาว “ชุติกาญจน์ พยัคฆะ” และคุณพ่อเจ้าบ่าว “ถนัต สามารถ” ได้รับการยืนยันจากผู้ใช้แล้ว
- ถ้าต้องการเปลี่ยนฉบับบนเว็บไซต์ ต้องแก้ค่า JSON ใน `#card-data` และนำขึ้นเว็บไซต์ใหม่ ข้อมูลร่างในเบราว์เซอร์ไม่ใช่ระบบหลังบ้าน
- เพิ่มลิงก์แผนที่ และลิงก์แบบฟอร์ม/LINE ยืนยันร่วมงานได้ ไม่มีการรับข้อมูลผู้ร่วมงานในเซิร์ฟเวอร์ของเว็บนี้

เพลง `our-little-melody.wav` สร้างขึ้นใหม่สำหรับแบบการ์ด ไม่มีการใช้เพลงเชิงพาณิชย์
ภาพในเว็บไซต์เป็นไฟล์ต้นฉบับที่ผู้ใช้ส่งให้ ไม่มีการแก้ไขภาพบุคคล
ร่างการ์ด Earn & Arm ใช้พื้นที่เก็บข้อมูลแยกจากแบบตัวอย่าง Pim & Pat เดิม จึงไม่โหลดข้อมูลสมมติเก่าทับข้อมูลจริง
Google Fonts และ YouTube ต้องใช้อินเทอร์เน็ต วิดีโอ YouTube ต้องอนุญาตให้ฝังได้
