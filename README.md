# Earn & Arm — 23 January 2027

หน้าร่วมแสดงความยินดีอยู่ที่ `wishes.html` เชื่อม Google Apps Script ไปยังชีตของผู้ใช้ พร้อมข้อความอวยพร รูปถ่าย สลิปส่วนตัว และดาวน์โหลดโปสการ์ด
ใช้ QR ธนาคารกรุงไทยต้นฉบับจากผู้ใช้ โดยไม่แก้ไขภาพ และตรวจรหัสแล้วว่าตรงกับพร้อมเพย์ 0623452359 ชื่อผู้รับนางสาวชุติกาญจน์ พยัคฆะ
รายละเอียดการเชื่อมต่อและทดสอบอยู่ใน `google-apps-script/README.md`

หน้าเว็บ HTML/CSS/JavaScript แบบ static อยู่ใน `dist/` ไม่ต้องติดตั้ง dependencies

## หน้าแขกกับหลังบ้าน

| ไฟล์ใน `dist/` | ใครใช้ | ทำอะไร |
|---|---|---|
| `index.html` | แขก | การ์ดเชิญ ไม่มีเครื่องมือแก้ไข ข้อมูลการ์ดอยู่ใน `<script id="card-data">` |
| `wishes.html` + `guestbook.*` | แขก | ส่งคำอวยพร รูป สลิป และโปสการ์ด ไปยัง Google Apps Script |
| `login.html` + `login.js` | คู่บ่าวสาว | ถามรหัสผ่านก่อนเข้าหลังบ้าน |
| `admin.html` + `admin.*` | คู่บ่าวสาว | หลังบ้าน: แก้การ์ดพร้อมดูตัวอย่างจริง จัดการรูป ทำลิงก์เชิญใส่ชื่อแขก และดาวน์โหลดไฟล์ |

- ตั้งหรือเปลี่ยนรหัสผ่านหลังบ้าน: `node scripts/set-admin-password.cjs` (พิมพ์สองครั้ง ไม่แสดงบนจอ อย่างน้อย 10 ตัวอักษร) แล้วนำ `dist/admin-auth.js` ขึ้นเว็บ ไฟล์นี้เก็บแค่ salt กับ hash แบบ PBKDF2 ไม่เก็บรหัสจริง เปลี่ยนรหัสแล้วทุกเครื่องที่เคยเข้าไว้ต้องเข้าใหม่ ลบรหัสด้วย `--clear`
- เป็นเว็บ static ไม่มีเซิร์ฟเวอร์ รหัสผ่านจึงกันคนทั่วไป แต่คนที่แก้โค้ดในเบราว์เซอร์เองยังข้ามได้ และ hash อยู่ใน repo สาธารณะ จึงควรใช้รหัสยาวที่ไม่ใช้ที่อื่น

- หน้าแขกไม่ลิงก์ไปหลังบ้าน และหลังบ้านตั้ง `noindex` ไว้ แต่เป็นไฟล์ static ใครรู้ที่อยู่ก็เปิดได้ การแก้ในหลังบ้านเก็บเป็นร่างในเบราว์เซอร์ของคนที่แก้เท่านั้น ไม่เปลี่ยนการ์ดที่แขกเห็น
- หลังบ้านโหลดข้อมูลจาก `index.html` ที่อยู่บนเว็บ แล้วส่งร่างไปแสดงในการ์ดจริงผ่าน `index.html?preview` (เปิดแบบนี้จะไม่มีหน้าปกและไม่เล่นเพลงเอง)
- เปลี่ยนการ์ดบนเว็บ: แก้ใน `admin.html` → กด **ดาวน์โหลดไฟล์ขึ้นเว็บ** ได้ `index.html` ที่ใส่ข้อมูลใหม่แล้ว → นำไปแทน `dist/index.html` และเผยแพร่ใหม่
- **ดาวน์โหลดการ์ดไฟล์เดียว** ฝังรูป ไอคอน เพลง และวิดีโอทั้งหมดในไฟล์เดียว เปิดได้โดยไม่ต้องมีไฟล์อื่น ลิงก์ร่วมอวยพรชี้ไปที่ `https://tanawat09.github.io/arm2027/wishes.html`
- ที่อยู่เว็บจริง Google Sheet และ Apps Script ที่หลังบ้านใช้ ตั้งไว้ต้น `dist/admin.js`
- วันงาน (ตามเวลาไทย) การ์ดขึ้นแถบ "วันนี้วันแต่งงานของเรา" และกำหนดการไฮไลต์พิธีที่กำลังจัดอยู่ ดูล่วงหน้าได้ด้วย `index.html?now=2027-01-23T08:30`
- ปุ่มแชร์ท้ายการ์ดส่งลิงก์การ์ดโดยตัด `?to=` ออก คนที่ได้รับต่อจึงไม่เห็นชื่อแขกคนอื่นบนหน้าปก

## ใช้งาน

- เปิด `admin.html` เพื่อเปลี่ยนชื่อ วันงาน สถานที่ ข้อความและกำหนดการ
- เพิ่มรูป เพลง MP3/M4A/WAV/OGG และวิดีโอ MP4/WebM หรือ YouTube
- แกลเลอรีเพิ่มได้สูงสุด 20 รูป จัดลำดับ แก้คำบรรยาย เลื่อนแนวนอน เปิดเต็มจอ ใช้ปุ่มลูกศร/ปัดภาพ และเล่นสไลด์โชว์ได้ เริ่มต้นว่างเพื่อรอรูปจริง
- เพลงเริ่มต้นใช้ไฟล์ `atlasaudio-wedding-606284.mp3` ที่ผู้ใช้แนบ เล่นเต็มเพลงและวนซ้ำเมื่อแตะเปิดคำเชิญหรือปุ่มเพลง โดยย้ายเฉพาะค่าเพลงในร่างเก่าและเก็บรูปแกลเลอรีเดิมไว้
- เพลง YouTube ที่เคยเลือกคือ “ดาวหางฮัลเลย์ — fellow fellow” (`WtcKJtwMD2E`) ตั้งช่วงตัวอย่าง 01:00–01:30 และปรับเวลาได้
- ทดสอบ YouTube ทั้ง youtube.com และ youtube-nocookie.com แล้วได้ error 150 (ไม่อนุญาตการฝัง) จึงแสดงลิงก์เปิดฟังบน YouTube ตามเวลาเริ่ม แทนการอ้างว่าเล่นเสียงบนการ์ดได้
- เวลาเริ่ม/จบและวนซ้ำรองรับผ่าน IFrame API สำหรับคลิปที่ฝังได้ ส่วนไฟล์เสียงอัปโหลดรองรับเลือกช่วงเวลาและวนซ้ำเช่นกัน
- ไม่ได้ดาวน์โหลด แยกเสียง ตัดเพลง หรือแปลงเพลงของ YouTube เป็นดนตรีล้วน หากต้องการเวอร์ชันบรรเลงให้เลือกไฟล์เสียงที่มี
- ร่างบันทึกใน IndexedDB ของเบราว์เซอร์ที่เปิดหลังบ้าน การแก้ไขร่างไม่เปลี่ยนเนื้อหาเว็บของผู้เข้าชมรายอื่น
- ใช้ข้อมูลจากรูปการ์ดที่เจ้าของส่งให้: ครูเอิญและครูอาร์ม วันเสาร์ที่ 23 มกราคม 2570 เริ่ม 07.00 น.
- ปุ่ม “ดูการ์ดเชิญฉบับเต็ม” เปิดรูปต้นฉบับโดยคงไฟล์เดิมไว้
- ใช้ลิงก์ Google Maps ที่ถอดจาก QR ของการ์ดต้นฉบับ
- ชื่อเจ้าสาว “ชุติกาญจน์ พยัคฆะ” และคุณพ่อเจ้าบ่าว “ถนัต สามารถ” ได้รับการยืนยันจากผู้ใช้แล้ว
- เพิ่มลิงก์แผนที่ และลิงก์แบบฟอร์ม/LINE ยืนยันร่วมงานได้ ไม่มีการรับข้อมูลผู้ร่วมงานในเซิร์ฟเวอร์ของเว็บนี้

เพลง `our-little-melody.wav` สร้างขึ้นใหม่สำหรับแบบการ์ด ไม่มีการใช้เพลงเชิงพาณิชย์
